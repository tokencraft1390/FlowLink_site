A sanitized white-label browser dashboard derived from the reusable parts of the FlowLink site.

- Affiliate program directory and tracking-link manager
- Revenue projection calculator
- Browser-local invoice tracker

- Wallet connection UI shell

## Explicitly excluded

- FlowLink-owned affiliate tracking URLs
- Any wallet addresses
- Any invoice/customer records
- Production payment credentials
- Company-specific policy or legal claims
